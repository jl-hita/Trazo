Estos valores no se editan aquí porque un error impediría arrancar la API o iniciar sesión. Cambiarlos exige editar /etc/trazo/trazo.env y reiniciar el servicio:

  • Cadena de conexión a PostgreSQL y claves de Data Protection.
  • Emisor, audiencia y clave de firma del JWT.
  • AllowedHosts, URL de escucha y orígenes CORS base.
  • Activar o desactivar el almacenamiento de logs en base de datos.
